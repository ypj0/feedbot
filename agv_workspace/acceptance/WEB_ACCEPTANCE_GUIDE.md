# 实车验证网页使用指南

## 功能特性

✅ **实时传感器监测**
- 扫描 (LiDAR) 频率
- IMU 频率
- 里程计频率
- EKF 滤波频率
- 实时位置、朝向、速度

✅ **诊断信息**
- 所有系统状态
- 警告和错误显示
- 实时更新

✅ **遥控运动**
- 虚拟摇杆（模拟遥感）
- 方向键按钮（↑↓←→）
- 紧急停止按钮

✅ **完全集成 MotionAuthority**
- 自动获取租约
- 通过 MotionRequest 发送命令
- 实时反馈

## 快速开始（3 步）

### 步骤 1：启动基础栈（车机端）

```bash

ssh feedbot@10.7.5.88

# 启动基础栈
cd /work
source /opt/ros/jazzy/setup.bash
```

```bash
python3 acceptance_web_backend.py

# 预期输出：
# ✓ WebSocket 服务启动于 ws://0.0.0.0:8765
# ✓ 访问 http://10.7.5.88:8765/acceptance.html
```

### 步骤 3：打开网页并控制（本地开发机）

```bash

http://10.7.5.88:8765/acceptance.html

# 或替换成车机实际 IP（查看启动脚本输出）
```

## 验收流程

### 验证 1：频率监测（静止 1 分钟）

1. 打开网页
2. **不发送任何运动命令**
3. 观察 60 秒
4. **预期**：
   - 扫描 14-16 Hz ✅
   - IMU 190-210 Hz ✅
   - 里程计 45-55 Hz ✅
   - EKF 45-55 Hz ✅
   - 诊断无红色 ✅

### 验证 2：轮转向（轮离地）

1. 车摆在支架上（轮离地）
2. 点击"摇杆"模式
3. 向上拖动摇杆 3 秒
4. **预期**：左右轮旋转，位置 Y 增加（向左偏）✅
5. 点击"方向键"模式
6. 点击左箭头 3 秒
7. **预期**：车左转 ✅

### 验证 3：停止命令

1. 点击"⏹️"按钮或摇杆松开
2. **预期**：速度立即降为 0 ✅

### 验证 4：已知距离（地面）

1. 切换到"方向键"模式
2. 标记起点，按 ⬆️ 5 次（每次 1 秒 → 总共 5 秒）
3. 在 0.1 m/s 速度下 → 应前进 ~0.5m
4. 按 ⏹️ 停止，标记终点
5. 重复 3 次，记录平均误差
6. **预期**：误差 < 2% ✅

## 故障排查

| 现象 | 原因 | 修复 |
|------|------|------|
| 网页打开但无数据 | 后端未启动 | 检查步骤 2 是否成功 |
| 页面"已断开，重试中" | WebSocket 连接失败 | 检查车机 IP 和防火墙 |
| 摇杆无反应 | 租约获取失败 | 检查 MotionAuthority 节点是否运行 |
| 诊断显示红色错误 | 系统异常 | 查看错误内容，重启对应模块 |
| 频率为 0 | 传感器未发布 | 检查 `ros2 topic list` |

## 技术细节

**后端**：`acceptance_web_backend.py`
- Python + AsyncIO + WebSockets
- ROS 2 节点（rclpy）
- 获取 MotionAuthority 租约
- 发送 MotionRequest 消息

**前端**：`acceptance.html`
- 单页应用（无依赖）
- 响应式设计（手机/平板友好）
- 虚拟摇杆（原生 JS）

**通信**：WebSocket
- 双向实时通信
- JSON 格式消息
- 100ms 更新频率

## 使用提示

✅ **最佳实践**
- 先用摇杆探索，再用方向键精确控制
- 频繁使用紧急停止按钮确认其有效
- 定期检查诊断信息（尤其是第一次启动）

⚠️ **安全注意**
- 轮离地时防止车摔落
- 周围无人时才发送运动命令
- 任何时刻都可按紧急停止

🔧 **调试**
- 浏览器开发者工具（F12）查看 WebSocket 消息
- 查看后端控制台输出诊断信息
