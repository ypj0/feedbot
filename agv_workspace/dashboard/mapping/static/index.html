手推建图流程

等待建图数据
  1. 在实物上解锁电机，确认车轮可自由滚动。
  2. 先推 20–30 cm，核对左右轮位置、里程计和地图车体同步变化。
  3. 缓慢推行覆盖目标区域，转弯放慢，避免遮挡雷达。
  4. 完成后停稳，点击保存地图，下载 YAML 和 PGM 放在同一目录。

本页不发送运动或电机解锁指令。只调用 ROS 2 保存，不调用原厂建图、脱桩、回充或地图加载服务。
