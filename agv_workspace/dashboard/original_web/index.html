建图操作
建图流程：
1. 点击"新建地图"进入建图模式
2. 用摇杆推动机器人扫描整个区域
3. 在充电桩前约0.5米、正对充电桩时，手动点击"添加充电桩"
4. 把机器人推到充电桩并进入充电，系统只会自动创建初始点（含姿态）
5. 在需要停靠的位置点"添加导航点"，系统按当前位置+姿态保存
6. 点击"保存并退出建图"完成
⚠ 充电点请在桩前约0.5米处手动添加；初始点需充电后自动生成或手动补建。
